How it works

Your image moves through this serverless pipeline.

↑
1. Secure upload

A presigned URL sends the image to the S3 uploads folder.

⚙
2. Automatic processing

An S3 event invokes Lambda to validate and resize the image.

▧
3. Three output sizes

Processed images are saved to separate S3 folders.

◷
4. Monitoring

CloudWatch captures execution logs and processing errors.
